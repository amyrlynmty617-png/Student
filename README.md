# Student AI Site V3

نسخه ارتقایافته V2 با پنل مدیریت کامل‌تر.

## امکانات مدیریت
- آمار کل کاربران، فعال‌ها، مسدودها و تحلیل‌ها
- جست‌وجوی کاربر
- مسدود/فعال‌سازی کاربر
- حذف کاربر و تحلیل‌هایش
- مشاهده همه تحلیل‌ها
- حذف تحلیل
- نقش admin/student
- جلوگیری از ورود حساب مسدودشده

## راه‌اندازی
1. Node.js نصب باشد.
2. `npm install`
3. `.env.example` را به `.env` تبدیل کنید.
4. `OPENAI_API_KEY` را تنظیم کنید.
5. `SESSION_SECRET` را به یک مقدار تصادفی طولانی تغییر دهید.
6. `ADMIN_USERNAME` و `ADMIN_PASSWORD` را تعیین کنید.
7. `npm start`
8. `http://localhost:3000`

اگر کاربر مدیر با `ADMIN_USERNAME` از قبل در دیتابیس وجود نداشته باشد، در اولین اجرای سرور ساخته می‌شود.

کلید API فقط روی سرور نگهداری می‌شود؛ آن را داخل HTML قرار ندهید.
